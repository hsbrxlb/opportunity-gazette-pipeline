# Agent rules

- This repository is public. Store only public-source candidate metadata and publication-safe reviewed output.
- Never add local absolute paths, private notes, account data, browser sessions, passwords, cookies, tokens, authorization headers, or other credentials.
- Keep excerpts short and source-linked. Do not copy full articles or posts.
- A candidate is not an approved opportunity. Only `reviewed/` files may contain editorial publication decisions.
- Preserve deterministic IDs, date boundaries, deduplication, failure states, and idempotent reruns.
- Run unit tests, validation, and the public repository scan before publishing changes.
